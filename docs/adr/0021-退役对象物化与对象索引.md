# 0021 退役对象物化与对象索引

- 状态：已采纳
- 日期：2026-10-20

## 决定

对象列表、全部标签、详情、实例图谱、智能问答和本体 SQL 统一按当前版本从 ODS / 业务源虚拟读取。ClickHouse 只保存 `ods_*` 原始源表镜像；不再保存对象实例、关系边或物化清单副本。

以下接口、后台任务和管理界面已删除：

- `/api/objects/materialize-type`
- `/api/objects/index`
- `/api/object-search/reindex`
- 旧对象索引统计接口
- 对象页「索引与物化」面板

`POST /api/objects/materialize` 保留，但含义仅为“按主键把源对象取进草稿快照”，用于编辑基线和动作对象，不是对象物化。

## 数据清理

- ClickHouse：删除 `materialization_manifests`、`object_entries`、`object_links` 与契约测试遗留空表。
- PostgreSQL：迁移 `0017` 防御性删除 `materialization_jobs`。

## 边界

- 源数据主键重复时不得静默折叠；读取和图谱必须报数或拒绝。
- 全部标签按类型有界分页；交互页拿满当前页后不再继续扫描其它类型。
- 普通读取不保证源数据实时更新到毫秒：ODS 新鲜度由同步时间决定。
- 旧快照中的 `indexPolicy` / `index` 参数只做结构兼容，不再选择对象副本。
