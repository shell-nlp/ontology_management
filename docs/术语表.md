# 本体平台术语表

## ODS 基础镜像

由业务源表同步到 ClickHouse 的当前数据镜像，按源表保存，所有版本共享。ODS 基础镜像只反映业务源同步结果，不直接承载某个版本的本地 CRUD。

## 草稿本地覆盖层

草稿版本在 PostgreSQL 中保存的稀疏对象与关系变更，用于手工 CRUD、动作 CRUD、本地新建对象和删除墓碑。草稿预览可以读取；发布前不会进入 ODS 有效数据视图。

## 发布版本变更集

发布成功后写入 ClickHouse、并绑定到具体版本的对象与关系 CRUD 变更。它是稀疏数据，只保存被本地修改的对象和关系，不是整份 ODS 副本。

对象变更与关系变更分别保存；每个版本保存相对 ODS 基础镜像的累计有效变更。

## 有效版本数据

查询某个发布版本时使用的统一数据视图：

```text
当前 ODS 基础镜像
  + 该版本的发布变更集
  = 有效版本数据
```

对象实例查询、关系子图查询和本体 SQL 必须使用同一份有效版本数据。

## 版本切换

切换本体定义和该版本绑定的发布变更集，不复制整份 ODS，也不把源业务数据回退到历史时点。源数据始终使用当前 ODS 基础镜像。

## 历史时点数据

某个业务时间点的源数据切片。它与普通版本切换是两个独立能力，不能依赖发布变更集模拟。
