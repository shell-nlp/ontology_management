# 虚拟实例与 ODS：实现范围和验收

## 当前读取口径

版本保存定义、映射和少量本地编辑；业务对象按查询生成。切换版本不创建新 ODS，不重新搬运全表。普通历史版本表示“历史定义作用在当前源数据”。

对象类型始终虚拟查询；来源的 `AUTO / DIRECT / ODS` 决定读取原库还是 ClickHouse ODS。旧 `FEDERATED / AUTO / INDEXED` 字段仅为历史快照兼容保留，不再选择对象索引。

## 完成的五项收尾

| 能力 | 入口与行为 | 边界 |
| --- | --- | --- |
| 显式多跳 | 实例图谱“邻域范围”选择 1～3 跳，加载业务对象或展开节点 | 最多 500 节点、2000 边；截断和无法读取端点会提示，悬空边不渲染 |
| 编辑覆盖 | 对象取进草稿后修改；源基线与本地对象保存在 PG 版本 `snapshot.objectEdits` | 只覆盖改过字段，源刷新仍更新其它属性；对覆盖字段的跨源筛选/排序与未写回编辑的本体 SQL 统计明确拒绝，避免错数 |
| 物化失效 | 物化清单保存定义版本、定义哈希和映射哈希；对象、搜索、图谱和问答读前核对 | 定义/映射变化或旧清单缺哈希时拒绝旧索引，重新物化；相同定义可跨版本复用，不因版本号变化重复存数据 |
| 历史采集 | 对象页“历史数据”，显式选类型后台采集 | 每页 gzip 压缩并校验 SHA-256；冻结采集定义和源投影；采集期间源可能变化，记录开始/结束区间，不宣称跨表事务一致时间点 |
| 按需预热 | 历史弹窗“预热”当前查询页 | 解压缓存上限 8 MiB、10 分钟；分页回看不解压整份历史；删除快照回收压缩页和缓存 |

本地新建、动作创建和源对象编辑沿版本继承；删除源对象是当前版本的隐藏标记，不删除业务行。恢复源数据会撤销覆盖和草稿中的相关本地关系。业务库写入继续只通过显式启用的动作写回。

## ODS 的正确性边界

- 一张源表一份镜像，源表主键可复合。全量镜像写影子表，成功对账后原子替换。
- 全量行数与唯一行键不一致时报告源主键重复，不发布被折叠的镜像。
- 增量检查点使用包含边界的重读；同水位行允许幂等重放，主键游标保证页推进。
- 全量取消不会替换在线表。增量取消可能已有部分页写入：检查点不推进，镜像暂停读取，完成重试或校准后恢复，不能宣称“旧镜像完全未改动”。
- 查询时先过滤每张 ODS 子表，再执行 JOIN，保留 LEFT JOIN 的未匹配主对象。
- 复合主键批量查询下推完整键组 OR；禁止各列独立 IN 形成交叉组合后再限行。
- 物化和历史采集使用源连接器的游标；不复用忽略游标的交互式 ODS 页面。

## OpenSearch 评估结论

本次只完成接入边界评估，维持用户“暂不引入 OpenSearch”的决定。当前目标是源表过滤、聚合与版本切换，现有 ODS 满足该架构目标，不增加新的部署组件。

未来如果将相关性搜索、模糊检索或向量检索作为产品核心能力，应新增独立 `SearchIndex` 契约及适配器；它保存可重建搜索文档，不接管本体版本、源数据和编辑权威。查询编排根据能力选择后端，不把 OpenSearch 查询语法泄漏给对象服务。实现前应使用共享契约验证索引更新/删除、租户隔离、过滤、排序与分页，并用实际数据测查询性能和重建成本。

此评估不表示已经部署 OpenSearch、已经生成 embedding，或已完成千万行性能压测。

## 验证入口

- 单元与架构回归：`pnpm test`、`pnpm typecheck`。
- ODS 真实契约：`pnpm test:ods`。
- 历史压缩与编辑持久化：`node --env-file=.env.local ./node_modules/vitest/vitest.mjs run tests/lib/history.contract.test.ts tests/lib/object-edits.contract.test.ts --testTimeout=30000`。
- 物化存储真实契约：`pnpm test:object-index`。
- 界面交互：在 3011 独立服务上运行 `pnpm exec playwright test e2e/virtual-instances.spec.ts`；使用可控接口数据验证界面，不等于业务源千万行实测。

真实服务契约只操作随机命名测试记录/表，并在结束时清理。用户的 3000 开发服务不属于测试进程。

本轮验证：单元回归 689 通过、23 跳过；包含真实 PostgreSQL/ClickHouse 契约的服务相关套件 40 通过；浏览器交互 2 通过；类型检查、改动文件 ESLint 与独立目录生产构建通过。浏览器验证使用受控接口数据，不能替代实际业务源千万行压测。
